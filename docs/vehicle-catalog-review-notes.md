当前识别出 99 组跨来源、同标准车型且三段尺寸完全一致的重复证据。重复证据不会删除，而是共用同一个标准雨刷配置并分别保留来源观察。另有 68 组同一车型目标出现不同雨刷配置，全部保持 `review`，不自动发布。

## 发布前必须确认

1. 先在测试 Supabase 执行 V2 migration。
2. 导入 Machter 主干并核对 21 条审核记录没有被发布为第三层实体。
3. 运行 `npm run wiper-sources:report`，确认报告哈希和数量未变化。
4. 再运行 `npm run wiper-sources:import`；该命令只把高置信匹配写成 `review`，发布数量始终为 0。
5. 审核 68 组配置冲突和 Sedan/Hatchback 候选后，才允许把选定适配改为 `published`。
